# JabarSupplyChainDataset
This repository contains datasets used in the study “Price Forecasting of West Java Rice using Multivariate Decomposition SARIMAX-Gated Recurrent Unit Combination.” It includes time series data on rice prices in West Java from 2021 to 2023, collected from multiple sources including the National Food Agency (BPN), Bank Indonesia, and the Central Bureau of Statistics (BPS). The datasets encompass various parameters such as harvest area, prices at different stages of the supply chain, production levels, and macroeconomic indicators relevant to the rice market. The dataset used in the study consists of 678 rows and 10 columns.
